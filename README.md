# anu-b-gone
## TRY TO BALANCE *THAT*

Solves any of [anubis](https://github.com/TecharoHQ/anubis)' JavaScript challenges without granting the website JS privilege (e.g. using uBlock).

Also makes sure you don't have to see the mascot.

Oh and that makes it's faster, too.

# Install
This is a Greasemonkey/Tampermonkey script.

Make sure you have the according Addon enbaled and load the  [anu-b-gone.user.js](https://github.com/tbware/anu-b-gone/raw/refs/heads/main/anu-b-gone.user.js) in this repo raw, then install.
